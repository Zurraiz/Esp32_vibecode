Concept Building
What is a Variable?
A variable is a place in the program where you can store a value.
You can think of a variable as:
A container
A box with a name
This box stores information that your program can use.
For example:
Store a number
Store a text message
Store a sensor value
Why Do We Use Variables?
Variables are used to:
Store information
Keep track of values
Use data later in the program
Without variables:
You cannot remember values
You cannot update information
With variables:
Programs become dynamic
Values can change during execution
Types of Variables
Different types of variables store different kinds of data:
Integer (var_int) → stores whole numbers (e.g., 5, 10)
Float (var_float) → stores decimal numbers (e.g., 25.5)
String (var_str) → stores text (e.g., "Hello")
Boolean (var_bool) → stores TRUE or FALSE
Choosing the correct type is important.
Storing a Value in a Variable
To store a value:
You create a variable
You assign a value to it
Example:
Store number 10 in a variable
Store button state (HIGH/LOW)
Once stored:
The program can use this value anytime
Updating a Variable
Variables are not fixed — they can be updated.
Example:
Start with value = 0
Increase value by 1 each time
This is called updating a variable.
It allows you to:
Count things
Track changes
Store new values
Using Variables in Programs
Variables can be used to:
Store input values
Use values in IF conditions
Control outputs
Example:
Store button state in a variable
Use that variable to decide LED behavior
This connects:
 Input → Variable → Condition → Output

## Example: Counter Using Variable

Example:
Start counter at 0
Increase by 1 each time
Display value
This is useful for:
Counting repetitions
Tracking events
Measuring activity
Variables with Sensors
Variables are very useful with sensors.
Example:
Read temperature from sensor
Store it in a variable
Use it in the program
This allows:
Real-world data to be used in logic
Smart decision making

## Key Insight of This Lesson

The most important concept in this lesson is:
Variables allow you to store, update, and use information inside your program.
You are now able to:
Remember values
Track changes
Use data to control behavior
This is essential for building dynamic, intelligent, and data-driven systems.
