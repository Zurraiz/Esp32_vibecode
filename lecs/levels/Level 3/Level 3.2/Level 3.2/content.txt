## 3. Concept Building


## 


## 3.1 Is the LED only ON or OFF?


## In earlier lessons, the LED behaved in only two ways:


## ON


## OFF


## Now you will notice something different.


## The LED can now exist at different levels of brightness:


## Dim


## Medium


## Bright


## This means the output is no longer binary—it is continuous.


## 


## 3.2 How is this possible?


## The ESP32 does not actually send “partial electricity.”


## Instead, it uses a technique called PWM (Pulse Width Modulation).


## It works by:


## Switching the signal ON and OFF extremely fast


## So fast that the human eye cannot detect it


## The result appears as different brightness levels


## So instead of changing electricity strength, it changes time patterns.


## What matters for you is simple:
👉 The value you provide controls how strong the output appears.


## 


## 3.3 What do PWM values represent?


## PWM uses numbers to control intensity.


## Typically:


## Low values → weak output


## Medium values → balanced output


## High values → strong output


## For example:


## Low value → LED barely visible


## Medium value → LED clearly visible


## High value → LED fully bright


## Each value represents how much time the signal stays ON compared to OFF.


## 


## 3.4 Understanding gradual control


## Unlike digital output:


## PWM does not switch instantly between ON and OFF


## Instead:


## It creates smooth transitions


## When values change gradually:


## Brightness increases step by step


## Brightness decreases step by step


## This makes the system feel natural and responsive.


## 


## 3.5 Why this matters in real systems


## PWM is used anywhere you need control instead of switching.


## Examples:


## Light dimming systems


## Fan speed control


## Motor speed regulation


## Audio volume control


## Instead of only “ON/OFF”, systems can now behave proportionally.


## 


## 3.6 Connecting input and output (important shift)


## Now we connect what you learned in 3.1.


## You can:


## Read a value from a sensor (photoresistor / potentiometer)


## Convert that value into a usable range


## Use it to control output brightness


## This creates a direct relationship:


## Low sensor value → dim LED


## High sensor value → bright LED


## Now the system is no longer static—it is responsive to the real world.


## 


## 3.7 What you may notice in real behavior


## When using real sensor values:


## Small changes in input cause small brightness changes


## Large changes produce noticeable differences


## Output feels smooth and continuous


## This shows that the system is not guessing—it is directly reacting to input values.

## }


## 


## 


## Code Explanation


## analogRead(sensorPin);
Reads sensor value (light or position)


## sensorValue / 16
Scales value to match PWM range


## ledcWrite()
Controls LED brightness


## 


## Execution Flow


## Sensor value is read


## Value is converted for output


## PWM updates LED brightness
