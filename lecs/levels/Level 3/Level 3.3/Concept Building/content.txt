
## LEVEL 3.3: Translating Values (Mapping Input to Output)


## 3. Concept Building


## 3.1 Why direct connection doesn’t work

Each sensor produces values in a large range.
For example:
Potentiometer → 0 to 4095
Photoresistor → 0 to 4095 (varies with light conditions)
But PWM output expects:
0 to 255
So if you connect them directly:
Most of the input range is not used properly
Output reacts too quickly or too weakly
Control feels inconsistent

## 3.2 Potentiometer: human control input

The potentiometer is your manual control device.
It represents:
Human intention
User-controlled input
But raw values are too large for direct output control.
Without conversion:
Small movements may cause big brightness jumps
Large movements may feel unresponsive in parts

## 3.3 Photoresistor: environmental input

The photoresistor represents the environment itself.
It does not respond to human input—it responds to:
Light intensity
Environmental changes
Without conversion:
Brightness control becomes unpredictable
Output does not fully reflect light changes

## 3.4 What is mapping actually doing?

Mapping converts a value from one range into another range while preserving its meaning.
It ensures:
Minimum input → minimum output
Maximum input → maximum output
Everything in between stays proportional
So instead of raw values:
0–4095 becomes 0–255
This allows both systems to communicate correctly.

## 3.5 Why proportional control matters

Mapping does not distort behavior—it preserves proportion.
For example:
25% knob rotation → 25% brightness
50% light intensity → 50% output
75% input → 75% output
This makes the system feel:
Predictable
Smooth
Natural

## 3.6 What changes after mapping?

Before mapping:
Output reacts unevenly
Some ranges feel useless
Control feels inaccurate
After mapping:
Full sensor range is usable
Output changes smoothly
System becomes responsive and stable

## 3.7 Connecting sensors and outputs properly

Now your system has a proper communication structure:
Potentiometer → manual brightness control
Photoresistor → automatic brightness control
Mapping → translation layer
PWM → physical output control
This is the first time your system behaves like a real control interface.

## 3.8 Key Insight of This Lesson

Sensors produce large-range values
Outputs require smaller, controlled ranges
Direct connection breaks behavior
Mapping translates values between systems
Proportional scaling preserves meaning
This enables accurate real-world control
