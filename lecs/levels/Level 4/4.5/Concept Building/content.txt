LEVEL 5.5: Pattern Systems (Complex LED Patterns)
## 3. Concept Building
## 3.1 What is a Pattern in Programming?
A pattern is a sequence of actions that repeats in a specific order.
In earlier lessons:
You controlled a single LED
You performed simple ON/OFF actions
Now:
You will create organized sequences
These sequences repeat to form patterns
A pattern is not random — it follows a planned order.
## 3.2 How Do Patterns Work?
Patterns are created using:
A sequence of steps
A specific order of execution
Repetition of that sequence
Example:
LED1 ON → LED1 OFF
LED2 ON → LED2 OFF
Repeat
This creates a visible pattern.
## 3.3 Using Multiple Outputs
To create patterns, you often use multiple LEDs.
Each LED:
Is connected to a different pin
Can be controlled independently
This allows:
Different LEDs to turn ON/OFF at different times
More complex and interesting patterns
## 3.4 Role of Timing in Patterns
Timing is very important in patterns.
Using delay:
Controls how long an LED stays ON or OFF
Affects the speed of the pattern
Example:
Short delay → fast pattern
Long delay → slow pattern
Timing makes patterns visible and meaningful.
## 3.5 Using Loops to Repeat Patterns
Loops are used to repeat patterns automatically.
Instead of writing the sequence many times:
You define the pattern once
Use a loop to repeat it
This creates:
Continuous patterns
Efficient programs
## 3.6 Combining Logic for Complex Patterns
Complex patterns are created by combining:
Multiple LEDs
Loops (repetition)
Timing (delay)
Conditions (optional)
Example:
LED1 → LED2 → LED3 → reverse sequence
This creates advanced visual effects.
## 3.7 Real-World Examples of Pattern Systems
Pattern systems are used in real life:
Traffic lights (Red → Yellow → Green)
Decorative lighting systems
Car indicators (running lights)
Display systems
All follow:
                  Sequence + Timing + Repetition

## 3.8 Key Insight of This Lesson


## The most important concept in this lesson is:

You can create structured and repeating patterns by combining sequence, timing, and loops.
You are now able to:
Control multiple outputs
Create ordered sequences
Build visually interactive systems
This is an important step toward designing complex embedded systems and creative projects.
