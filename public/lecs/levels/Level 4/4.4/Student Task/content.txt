
## Task: Create a Multi-LED Pattern System

Your objective is to create a system that:
Controls multiple LEDs
Turns LEDs ON and OFF in a specific sequence
Repeats the sequence to form a visible pattern

## Requirements


```cpp
Use pinMode to configure multiple LED pins as OUTPUT
```

Use dw_high and dw_low to control each LED
Use delay_ms or delay_sec to control timing
Use for_loop (or loop structure) to repeat the pattern
Ensure correct order of execution (sequence matters)

## Expected Behavior

When the system runs:
LEDs should turn ON one by one in sequence (e.g., LED1 → LED2 → LED3)
Each LED should turn OFF before the next one turns ON
The pattern should repeat continuously
The speed of the pattern should be controlled using delay

## Code Explanation


```cpp
digitalWrite(led3, HIGH);
delay(300);
digitalWrite(led3, LOW);
}
pinMode(...)
 Sets all LED pins as output.
digitalWrite(HIGH/LOW)
 Controls each LED individually.
delay(300);
 Controls how long each LED stays ON.
```

Sequence of instructions
 Creates the pattern by turning LEDs ON one after another.

## Execution Flow

Setup configures all LED pins
Loop starts execution
LED1 turns ON → OFF
LED2 turns ON → OFF
LED3 turns ON → OFF
Sequence completes
Loop repeats continuously
