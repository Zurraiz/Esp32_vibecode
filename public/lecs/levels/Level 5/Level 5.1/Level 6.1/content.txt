## 3. Concept Building


## 3.1 What is a sensor?

A sensor is a component that reads information from the physical world and converts it into data that the ESP32 can understand.
Instead of manually providing input (like a slider), the system now receives input from the environment itself.
In this lesson, the sensor measures:
Temperature (heat level)
Humidity (moisture in air)

## 3.2 What is the DHT sensor doing?

The DHT sensor continuously monitors the environment and sends updated values to the ESP32.
It does not give a single fixed value. Instead:
It keeps measuring
It keeps updating
It reflects real-world changes
This means the input is now external and dynamic, not manually controlled.

## 3.3 Why do values change over time?

You will notice that temperature and humidity values are not always stable.
This happens because:
The environment is always changing slightly
Air movement affects readings
Heat sources affect temperature
Humidity varies naturally
So even if nothing seems to change, the sensor may still show small variations.

## 3.4 Understanding real-world input

Unlike previous lessons where:
You controlled the input manually
Now:
The environment controls the input
This is a major shift.
The system is no longer just reacting to user input—it is reacting to real conditions.

## 3.5 Why sensors are important

Sensors allow systems to:
Understand their surroundings
Make decisions based on real conditions
React to changes without human input
This is the foundation of all smart systems:
Smart homes
Weather stations
Industrial monitoring
IoT devices

## 3.6 How the ESP32 reads sensor data

The process is simple:
The sensor measures temperature and humidity
It sends this data to the ESP32
The ESP32 reads the values
The values are then used in your program
This happens repeatedly in a loop, so the system always stays updated.

## 3.7 Why Serial is important here

Since sensor values change over time, you need a way to observe them.
Serial output allows you to:
See live data
Track changes over time
Understand environmental behavior
Without Serial, the data would exist but remain invisible.

## 5. Arduino Mapping


## Generated Code

#include "DHT.h"
#define DHTPIN 4
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);
void setup() {
Serial.begin(9600);
dht.begin();
}
void loop() {
float temperature = dht.readTemperature();
float humidity = dht.readHumidity();
Serial.print("Temperature: ");
Serial.println(temperature);
Serial.print("Humidity: ");
Serial.println(humidity);
}

## Code Explanation

dht.begin();
Initializes the sensor
readTemperature();
Gets current temperature value
readHumidity();
Gets current humidity value
Serial.print/println();
Displays real-time data

## Execution Flow

Sensor is initialized
Temperature is read
Humidity is read
Values are printed
Loop repeats continuously
